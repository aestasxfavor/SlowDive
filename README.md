# Slow Dive

잔잔한 바다를 탐사하며 생물을 포획·수집하고, 도감과 교환을 통해 다음 탐사를 이어가는 2D 잠수 탐사 게임

## 게임 개요
- 프로젝트 진행 시기: 2025.10 ~ 2026.07
- 실제 개발 기간: 약 4개월
- 개발 인원: 1명
- 개발 환경: Unity 6, C#
- 버전 관리 도구: GitHub Desktop
- 플랫폼: Windows PC
- 게임 장르: 2D 잠수 탐사·수집 게임

## 게임 소개
Slow Dive는 바다를 탐사하며 다양한 생물을 포획하고, 수집한 표본을 도감에 기록하거나 교환하는 2D 잠수 탐사·수집 게임입니다. 
산소 시스템을 통해 탐사와 귀환이 자연스럽게 반복되도록 구성했으며, 육지에서 수집 결과를 확인하고 다음 탐사를 준비할 수 있습니다.
빠른 보상과 강한 자극보다는 잔잔한 탐사와 반복적인 수집 과정에서 편안한 흐름을 느낄 수 있도록 제작했습니다.

## 게임 플레이 흐름
육지 → 잠수 → 탐사 및 포획 → 귀환 → 결과 확인 → 수집 결과 관리 → 재탐사 


## 주요 기능
- 플레이어 이동 및 작살을 활용한 생물 포획
- 산소 소모 및 자동 귀환 시스템
- 포획한 생물의 인벤토리 및 보관함 관리
- 생물 도감 등록 및 신규 발견 확인
- 표본 교환 및 아이템 상점
- 탐사 결과 확인
- 게임 진행 데이터 저장 및 불러오기
- 씬 전환 및 로딩 UI


## 핵심 구현
- 오브젝트 풀링을 활용한 작살 생성 및 재사용
- 산소 소모, 자동 귀환, 로딩 화면, 탐사 결과 UI를 연결한 탐사 사이클
- 포획 데이터를 인벤토리·도감·보관함·교환 상점에 연동
- JSON 기반 게임 진행 데이터 저장 및 불러오기
