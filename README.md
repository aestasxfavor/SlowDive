# Slow Dive

한 줄 프로젝트 소개

## 게임 개요
- 개발 기간: 2025년 10월 15일 ~ 2026년 
- 개발 인원: 1명
- 사용 기술: Unity, Github
- 게임 장르: 

## 게임 소개
게임의 목표와 특징을 2~3문장으로 설명

## 게임 플레이 흐름
육지 → 잠수 → 탐사 및 포획 → 귀환 → 결과 확인 → 도감 및 교환 → 재탐사 

## 주요 기능
- 플레이어 이동 및 작살 전투
- 산소 시스템과 자동 귀환
- 물고기 포획 및 보관함
- 생물 도감과 신규 발견
- 표본 교환 및 상점
- 데이터 저장
- 씬 전환과 로딩 UI

## 핵심 구현
- 오브젝트 풀링 기반 작살 관리
- 잠수부터 귀환까지 이어지는 게임 흐름
- 포획 데이터와 도감·보관함·교환 상점 연동
